# CS300-DSA-Analysis-and-Design

In the projects for this course, the problem being solved was to create a data structure to hold and print in alphanumeric order, a list of courses and their prerequisite courses.
I made sure to make a function to alter the user's inputs to be all uppercased letters so that the program could correctly find the course being searched for.
I've approached this problem by first taking into consideration what was being requested, software to help ABCU's computer science advisiors access course informaton for students.
I created multiple different data structures and their methods to print out their data, and compared their benefits and drawbacks which included their runtime complexity in Big O notation.
Understanding why data structures are so important can help with keeping the software move as fast and efficient as possible.
Any roablocks that I encountered while going through the actiivties or project were resolved by me doing a bit more research to find more information on how I could implement the data structures.
Working on this project has expanded my approach to designing software and developing programs by causing me to try to take more careful consideration in what data structures the software should use.
This project has ultimately only served to help me become better at writting psuedocode better than I had before, I've always tried to keep my programs as readable,maintainable and adaptable as possible,
and with the better understanding from this project about data structures, their runtime and space complexities amongs some other things.
